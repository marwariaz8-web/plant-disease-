# Plant Disease Detection using CNN

## Project Overview
This project uses a Convolutional Neural Network (CNN) to detect plant diseases from leaf images using the PlantVillage dataset.

## Features
- Image classification using CNN
- Data preprocessing and augmentation
- Model training and evaluation
- Disease prediction from leaf images

## Dataset
PlantVillage Dataset

## Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Google Colab

## Results
The model was trained on the PlantVillage dataset and achieved good classification accuracy on the validation and test datasets.
